关系式的层次 3(a)—(d)

固定编号：T01-01-M027

教材出处：《没有眼泪的拓扑》，书内第 17 页 / PDF 第 17 页，习题 1.1 第 3(a)—(d) 题。
学习目标：把属于号左边作为一个完整对象，判断再加一层花括号是否改变其成员资格。

本段主线：完成习题 1.1 第 3 题，分清点、底集和拓扑之间的关系。
当前环节：从前四个属于关系开始，检查底集、空集及它们的单元素集合。
这一步只做：看清左边整个对象，再判断它是否是右边的成员。

来源说明：B 保留原题第 3(a)—(d) 项的关系式；讲解与 A 为新增。原提示的计数问题和下面的教学约定均单独说明。

习题 1.1 第 3 题：共同题设

原题给定

X={a,b,c,d,e,f}, X=\{a,b,c,d,e,f\},

且 τ\tau 是 XX 上的离散拓扑，要求判断所列关系式是否正确。全部 16 项按原顺序分在 M027—M030。

原页提示为：“有且只有6个上述关系式正确。”

原提示问题：对照原式，至少有七项可以由题设保证成立，因此“只有六项”的计数不成立。下面逐项判断，不为凑足六项改变原式；完整核对表放在 M030 的折叠区域。

本组新增教学约定：沿用 M002—M003 的棋子解释，把 a,b,c,d,e,fa,b,c,d,e,f 看作六个不同的普通点标签，与空集、单点集等本题讨论的集合对象区分，不把点本身作为集合来讨论。新增题中的小写字母也采用这个约定。这个解释是课件明确加入的，不能说原题已经说明点的内部结构。

方法：花括号改变了正在检查的对象

例如，𝒞={⌀,{r}}\mathcal C=\{\varnothing,\{r\}\} 的两个成员是空集和单点集 {r}\{r\}。所以 ⌀∈𝒞\varnothing\in\mathcal C，但 {⌀}∉𝒞\{\varnothing\}\notin\mathcal C：后者是以空集为唯一元素的另一个集合，未被列入。

在离散拓扑中也要这样检查。一个对象属于 τ\tau，要求它是 XX 的一个子集。特别地，判断 {X}∈τ\{X\}\in\tau 时，左边集合的唯一元素是整个 XX；不能把它看成 XX 本身。

例题 A

新增题 A。令 Y={p,q}Y=\{p,q\}，其中 p,qp,q 为两个不同的普通点。给出集合簇

𝒜={⌀,Y,{⌀}}. \mathcal A=\{\varnothing,Y,\{\varnothing\}\}.

这里仅用 𝒜\mathcal A 练习成员资格，不将它称作 YY 上的拓扑。逐项判断并说明理由：

  1. Y∈𝒜Y\in\mathcal A；
  2. {Y}∈𝒜\{Y\}\in\mathcal A；
  3. {⌀}∈𝒜\{\varnothing\}\in\mathcal A；
  4. ⌀∈𝒜\varnothing\in\mathcal A。

A 解答

展开 A 的逐步解答

先列出 𝒜\mathcal A 的三个直接成员：⌀\varnothing、YY、{⌀}\{\varnothing\}。

  1. 成立。整个 YY 正是其中一个成员。
  2. 不成立。{Y}\{Y\} 以 YY 为唯一元素，不是空集；它也不是两点集 YY，更不是以空集为唯一元素的 {⌀}\{\varnothing\}。
  3. 成立。这次成员表确实直接列出了 {⌀}\{\varnothing\}，因此它属于 𝒜\mathcal A。
  4. 成立。⌀\varnothing 也被直接列为成员。

第三项成立的理由是这份成员表把相应对象收下了；不能仅因为它带有花括号就判为不成立。

练习 B：习题 1.1 第 3(a)—(d) 题

回到原题：X={a,b,c,d,e,f}X=\{a,b,c,d,e,f\}，τ\tau 是 XX 上的离散拓扑；按上面明示的普通点标签约定，判断并说明理由：

(a) X∈τ;(b) {X}∈τ;(c) {⌀}∈τ;(d) ⌀∈τ. \text{(a) }X\in\tau;\qquad \text{(b) }\{X\}\in\tau;\qquad \text{(c) }\{\varnothing\}\in\tau;\qquad \text{(d) }\varnothing\in\tau.

本组原题待核验，仅供查阅约定及条件化解答；不记录正常评分或进入复习排期。

B 解答

做过 B 后，展开四项解答
  • (a) 成立。XX 是自身的子集，所以被离散拓扑收下；也可直接由拓扑定义的条件 (i) 得到 X∈τX\in\tau。
  • (b) 不成立。{X}\{X\} 的唯一元素是整个集合 XX，而原题底集的六个成员是六个普通点，没有把 XX 本身作为一个点。因此 {X}\{X\} 不是 XX 的子集，不属于 τ\tau。
  • (c) 不成立。{⌀}\{\varnothing\} 的唯一元素是空集；在本组约定下，空集不是底集中的六个点之一。因此 {⌀}\{\varnothing\} 不是 XX 的子集，不属于 τ\tau。
  • (d) 成立。空集是 XX 的子集，属于离散拓扑；拓扑定义的条件 (i) 也直接保证这一点。

与 A 相比，(c) 的结果改变了：A 的集合簇明确列入了 {⌀}\{\varnothing\}，这里的离散拓扑只收 XX 的子集，而 {⌀}\{\varnothing\} 不满足这个要求。

简短回顾

属于号检查左边整个对象；XX 与 {X}\{X\}、⌀\varnothing 与 {⌀}\{\varnothing\} 各是不同对象。前四项已经完成，接下来检查属于号右边换成底集后会发生什么。
