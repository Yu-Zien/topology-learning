子集簇：集合的集合

固定编号：T01-01-M003
内容版本：0.1（首批试学稿）
教材出处：《没有眼泪的拓扑》，书内第 13 页 / PDF 第 13 页，定义 1.1.1 开头“XX 的子集簇”。
学习目标：列出一个候选簇的直接成员，并逐一检查它们是否都是指定底集的子集。

来源说明：“XX 的子集簇”来自教材定义 1.1.1；下面的分层解释、空集补充、A／B 题和参考解均为新增内容，不是教材原题。本模块只解释定义开头的这个短语。小写字母仍表示不同棋子本身。

短讲解

沿用上一个模块的两枚棋子，令 X={a,b}X=\{a,b\}。从 XX 中选出的 {a}\{a\} 和 {a,b}\{a,b\} 都是它的子集。现在把这两个集合本身作为成员，再组成一个集合：

𝒞={{a},{a,b}}. \mathcal C=\bigl\{\{a\},\{a,b\}\bigr\}.

读最外面一层花括号：𝒞\mathcal C 的两个直接成员是 {a}\{a\} 和 {a,b}\{a,b\}。不要拆开里面的花括号，把里面的棋子当成 𝒞\mathcal C 的直接成员。

因此，{a}∈𝒞\{a\}\in\mathcal C 成立：集合 {a}\{a\} 本身就是其中一个成员。a∈𝒞a\in\mathcal C 则不成立：棋子 aa 出现在某个成员里面，并没有被单独列为 𝒞\mathcal C 的直接成员。

这个 𝒞\mathcal C 的每个成员都是 XX 的子集，我们就说它是 XX 的子集簇。这里的 XX 叫作底集，即检查成员时所依据的集合。“簇”在这里就是把若干集合收在一起形成的集合，不要求收齐底集的所有子集。

空集和只含空集的集合

没有任何元素的集合叫作空集，记为 ⌀\varnothing。把空集本身作为一个元素，再组成的集合是 {⌀}\{\varnothing\}。

对象 它直接有哪些元素？ 元素个数
⌀\varnothing 没有任何元素 0
{⌀}\{\varnothing\} 唯一元素是空集 ⌀\varnothing 1

两者不能混同。对眼前的底集 X={a,b}X=\{a,b\}：

  • ⌀\varnothing 是 XX 的子集。子集要求左边的每个元素都在 XX 中；空集没有元素，因此没有元素违反这个要求。
  • {⌀}\{\varnothing\} 不是 XX 的子集。它有一个元素 ⌀\varnothing，但 XX 的元素是两枚棋子 a,ba,b，没有空集这个元素。

这里对 {⌀}\{\varnothing\} 的判断依赖给定的底集，不能说它永远不是任何集合的子集。判断候选簇时，始终做同一个动作：先列出直接成员，再检查每个成员里面的元素是否都在底集中。

例题 A

新增题 A。

a,b,ca,b,c 是三枚不同的棋子。给定底集和候选簇：

X={a,b},𝒜={⌀,{a},{⌀},{b,c}}. X=\{a,b\},\qquad \mathcal A=\bigl\{\varnothing,\{a\},\{\varnothing\},\{b,c\}\bigr\}.

列出 𝒜\mathcal A 的直接成员，逐一判断它们是否是 XX 的子集，并据此判断 𝒜\mathcal A 是否为 XX 的子集簇。

A 解答

展开 A 的逐步解答

第一步：只看最外层花括号，列出直接成员。

𝒜\mathcal A 的四个直接成员依次是：⌀\varnothing、{a}\{a\}、{⌀}\{\varnothing\}、{b,c}\{b,c\}。其中 ⌀\varnothing 和 {⌀}\{\varnothing\} 是两个不同的成员。

第二步：把每个成员作为一个集合，检查它里面的元素。

直接成员 是 XX 的子集吗？ 逐项依据
⌀\varnothing 是 它没有元素，不会有元素落在 XX 外。
{a}\{a\} 是 它的唯一元素 aa 属于 XX。
{⌀}\{\varnothing\} 否 它的唯一元素是空集，而空集不是 XX 列出的棋子 aa 或 bb。
{b,c}\{b,c\} 否 bb 在 XX 中，但 cc 不在 XX 中。

第三步：根据检查结果回答。

𝒜\mathcal A 不是 XX 的子集簇，因为并非每个成员都是 XX 的子集。这里有两个不合格成员：{⌀}\{\varnothing\} 和 {b,c}\{b,c\}。

它们仍然是 𝒜\mathcal A 的成员；不合格说的是“不满足作为 XX 的子集的要求”，不是说它们没有被列在 𝒜\mathcal A 中。

相似练习 B

新增题 B。

p,q,rp,q,r 是三枚不同的棋子。给定底集和候选簇：

Y={p,q,r},ℬ={{p,r},{⌀},⌀,{q,r}}. Y=\{p,q,r\},\qquad \mathcal B=\bigl\{\{p,r\},\{\varnothing\},\varnothing,\{q,r\}\bigr\}.

列出 ℬ\mathcal B 的直接成员，逐一判断它们是否是 YY 的子集，并据此判断 ℬ\mathcal B 是否为 YY 的子集簇。

B 解答

做过 B 后，展开逐步解答

第一步：列出直接成员。

ℬ\mathcal B 的四个直接成员依次是：{p,r}\{p,r\}、{⌀}\{\varnothing\}、⌀\varnothing、{q,r}\{q,r\}。不要把第二个成员 {⌀}\{\varnothing\} 和第三个成员 ⌀\varnothing 合成一项。

第二步：逐个检查是否为 YY 的子集。

直接成员 是 YY 的子集吗？ 逐项依据
{p,r}\{p,r\} 是 pp 和 rr 都属于 YY。
{⌀}\{\varnothing\} 否 它的唯一元素是空集，而 YY 的元素只有棋子 p,q,rp,q,r，没有空集。
⌀\varnothing 是 它没有元素，不会有元素落在 YY 外。
{q,r}\{q,r\} 是 qq 和 rr 都属于 YY。

第三步：根据检查结果回答。

ℬ\mathcal B 不是 YY 的子集簇。这里仅 {⌀}\{\varnothing\} 不满足要求，但一个不合格成员就足以否定“每个成员都是 YY 的子集”。

T01-01-R002

问题：⌀\varnothing 和 {⌀}\{\varnothing\} 分别有几个元素？后者的唯一元素是什么？

回忆后查看答案

⌀\varnothing 有 0 个元素；{⌀}\{\varnothing\} 有 1 个元素，那个元素就是空集 ⌀\varnothing。外层加上花括号后，得到的是以空集为元素的单元素集合。

一句小结

判断是否为底集的子集簇，要逐个检查外层成员，而检查每个成员时再看它里面的元素。
