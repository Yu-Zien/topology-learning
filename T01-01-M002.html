元素与子集是两种关系

固定编号：T01-01-M002
内容版本：0.1（首批试学稿）
教材出处：《没有眼泪的拓扑》，书内第 13 页 / PDF 第 13 页，定义 1.1.1 开头的集合基础短补。
学习目标：面对一个列出全部元素的集合，能区分属于与包含，并说明给定关系式是否成立。

来源说明：教材定义 1.1.1 直接使用“集”和“子集簇”。下面对元素、单点集、属于与包含的解释，以及 A／B 题和参考解，均为新增基础补充，不是教材原题。本模块中的小写字母表示不同棋子本身。

短讲解

桌上有两枚不同的棋子，分别标为 aa、bb。把它们作为一个集合，记作

X={a,b}. X=\{a,b\}.

花括号列出了这个集合的全部元素。aa 是其中一个元素，写作 a∈Xa\in X，读作“aa 属于 XX”。

现在只选出棋子 aa，组成集合 {a}\{a\}。它只有一个元素，叫作单点集。aa 是那枚棋子，{a}\{a\} 是以这枚棋子为唯一元素的集合，两者要区分。

因为 {a}\{a\} 的每个元素都在 XX 中，所以 {a}\{a\} 是 XX 的子集，写作

{a}⊆X. \{a\}\subseteq X.

这里的 ⊆\subseteq 读作“包含于”，允许两边相等；例如 {a,b}⊆X\{a,b\}\subseteq X 也成立。检查子集时，要逐个查看左边集合的元素：全部在右边才成立，有一个不在就不成立。

两种检查的区别是：

写法 检查什么
a∈Xa\in X 把 aa 当作一个完整对象，看它是否是 XX 的元素。
{a}⊆X\{a\}\subseteq X 查看左边集合的每个元素，看它们是否全都属于 XX。

因此，“是子集”不自动表示“是元素”。这个 XX 列出的元素是棋子 aa 和 bb，没有把集合 {a}\{a\} 列为一个元素，所以 {a}∈X\{a\}\in X 不成立。把“不属于”写成符号就是 ∉\notin。

例题 A

新增题 A。

a,b,ca,b,c 是三枚不同的棋子，X={a,b}X=\{a,b\}。判断下列关系式是否成立，每项用一句话说明理由。

  1. a∈Xa\in X。
  2. {a}∈X\{a\}\in X。
  3. {a}⊆X\{a\}\subseteq X。
  4. {a,c}⊆X\{a,c\}\subseteq X。

A 解答

展开 A 的逐步解答

先读右边的集合：XX 的全部元素就是棋子 aa 和 bb。再按每一项的关系符号进行检查。

  1. 成立。这里是属于关系。棋子 aa 本身就是 XX 列出的一个元素。
  2. 不成立。这里仍是属于关系，左边的整个对象是集合 {a}\{a\}。XX 列出的是棋子 a,ba,b，没有集合 {a}\{a\} 这个元素。
  3. 成立。这里是包含关系。左边集合 {a}\{a\} 只有元素 aa，而 aa 属于 XX，所以它的每个元素都在 XX 中。
  4. 不成立。左边集合有元素 aa 和 cc。虽然 aa 在 XX 中，但 cc 不在；一个不符合的元素就足以否定包含关系。

相似练习 B

新增题 B。

p,q,r,sp,q,r,s 是四枚不同的棋子，Y={p,q,r}Y=\{p,q,r\}。判断下列关系式是否成立，每项用一句话说明理由。

  1. {p,r}⊆Y\{p,r\}\subseteq Y。
  2. s∈Ys\in Y。
  3. {q}∈Y\{q\}\in Y。
  4. {q,s}⊆Y\{q,s\}\subseteq Y。

B 解答

做过 B 后，展开逐步解答

先读右边的集合：YY 的全部元素是棋子 p,q,rp,q,r。接着分别检查属于或包含关系。

  1. 成立。左边集合的元素是 pp 和 rr，两者都在 YY 中，所以 {p,r}⊆Y\{p,r\}\subseteq Y。
  2. 不成立。棋子 ss 没有被列为 YY 的元素；也可以写成 s∉Ys\notin Y。
  3. 不成立。左边的完整对象是集合 {q}\{q\}。YY 的元素是三枚棋子，没有把这个单点集列为元素。qq 属于 YY，不等于 {q}\{q\} 属于 YY。
  4. 不成立。检查左边的两个元素：qq 在 YY 中，ss 不在；因此并非每个元素都在 YY 中。

T01-01-R001

问题：X={a,b}X=\{a,b\}，其中 a,ba,b 是两枚不同棋子。a∈Xa\in X 和 {a}⊆X\{a\}\subseteq X 各在检查什么？

回忆后查看答案

a∈Xa\in X 检查棋子 aa 本身是否是 XX 的元素；{a}⊆X\{a\}\subseteq X 检查左边集合的每个元素是否都在 XX 中。这里左边只有元素 aa，所以两式都成立，但表达的是两种关系。

一句小结

属于关系检查一个完整对象是否是元素，包含关系检查一个集合的每个元素是否都在另一个集合中。
