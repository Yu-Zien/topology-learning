关系式的层次 3(m)—(p)

固定编号：T01-01-M030
内容版本：0.1
教材出处：《没有眼泪的拓扑》，书内第 17 页 / PDF 第 17 页，习题 1.1 第 3(m)—(p) 题及第 3 题总核对。
学习目标：使用包含号前检查左边的对象类型，再按其元素判断包含关系。

本段主线：完成习题 1.1 第 3 题，分清点、底集和拓扑之间的关系。
当前环节：进入最后四项，并收束全部十六项的判断。
这一步只做：先确认左边是作为集合给出的对象，再逐个检查它的元素。

来源说明：B 保留原题第 3(m)—(p) 项；讲解和 A 为新增。仍按 M027 明示的普通点标签约定作答，原提示问题在总核对中保留说明。

方法：先查对象类型，再查元素

例如，对两点集 Y={p,q}Y=\{p,q\} 和 𝒞={⌀,Y,{p}}\mathcal C=\{\varnothing,Y,\{p\}\}，要检查 Y⊆𝒞Y\subseteq\mathcal C，就得分别检查点 p,qp,q 是否属于 𝒞\mathcal C。它们都没有直接列在 𝒞\mathcal C 中，因此包含关系不成立。

但 {Y}⊆𝒞\{Y\}\subseteq\mathcal C 要检查的唯一元素是整个 YY，而 YY 确实属于 𝒞\mathcal C，所以这一个包含关系成立。不能只因为两式都有字母 YY 就作同一判断。

还要先留意左边是不是作为集合给出的对象。按本组的普通点约定，pp 只是点标签，未作为有一份元素表的集合来讨论；p⊂𝒞p\subset\mathcal C 在这个语境下类型不合。不能仅因为写下了包含号，就自动把一个点改成集合 {p}\{p\}。

例题 A

新增题 A。令 Y={p,q}Y=\{p,q\} 为两点集，𝒜={⌀,Y,{p}}\mathcal A=\{\varnothing,Y,\{p\}\}。判断下面的写法；若类型不合，指出问题。成立的包含式还需说明两边不相等。

  1. Y⊂𝒜Y\subset\mathcal A；
  2. {⌀,Y}⊂𝒜\{\varnothing,Y\}\subset\mathcal A；
  3. {{q}}⊂𝒜\bigl\{\{q\}\bigr\}\subset\mathcal A；
  4. p⊂𝒜p\subset\mathcal A。

A 解答

展开 A 的逐步解答
  1. 不成立。YY 的元素是点 p,qp,q；例如 p∉𝒜p\notin\mathcal A，所以不能说 YY 的每个元素都在 𝒜\mathcal A 中。
  2. 成立，且是真包含。左边的两个元素 ⌀\varnothing 与 YY 都属于 𝒜\mathcal A；右边另有 {p}\{p\} 这个不同成员，因此两边不相等。
  3. 不成立。左边的唯一元素是单点集 {q}\{q\}。它不等于 ⌀\varnothing、YY 或 {p}\{p\}，所以不属于 𝒜\mathcal A，包含关系失败。
  4. 按本组约定类型不合。pp 是一个普通点，没有作为集合给出，不能在这个语境中把它直接放在包含号左边，按集合的元素逐个检查。把它改写成 {p}\{p\} 会得到另一个表达式，不是为原式自动补全记号。

练习 B：习题 1.1 第 3(m)—(p) 题

令 X={a,b,c,d,e,f}X=\{a,b,c,d,e,f\}，τ\tau 为 XX 上的离散拓扑。按本组的普通点标签约定，判断原式并说明理由：

(m) X⊂τ;(n) {a}⊂τ;(o) {X}⊂τ;(p) a⊂τ. \text{(m) }X\subset\tau;\qquad \text{(n) }\{a\}\subset\tau;\qquad \text{(o) }\{X\}\subset\tau;\qquad \text{(p) }a\subset\tau.

本组原题待核验，仅供查阅约定及条件化解答；不记录正常评分或进入复习排期。

B 解答

做过 B 后，展开四项解答
  • (m) 不成立。左边 XX 的元素是六个普通点；例如 a∉τa\notin\tau。τ\tau 收下的是这些点组成的子集，所以不能把 X∈τX\in\tau 换成 X⊂τX\subset\tau。
  • (n) 不成立。左边只有元素 aa，因此包含关系要求 a∈τa\in\tau，而这在普通点标签约定下不成立。已经成立的 {a}∈τ\{a\}\in\tau 不能作为它的依据。
  • (o) 成立，且是真包含。左边的唯一元素是 XX，拓扑条件 (i) 保证 X∈τX\in\tau，所以 {X}⊆τ\{X\}\subseteq\tau。又有 ⌀∈τ\varnothing\in\tau 且 ⌀≠X\varnothing\ne X，所以两边不相等。
  • (p) 按本组约定类型不合。aa 是普通点标签，未作为集合给出；这里不能使用对子集逐元素检查的写法，也不能擅自把原式的 aa 改成 {a}\{a\}。

本组唯一成立的包含式 (o) 两边不相等，因此把原文 ⊂\subset 理解为真包含或允许相等的包含，均得到相同判断。

习题 1.1 第 3 题：全部关系式核对

完成十六项后，展开总核对

以下完整判断采用本组已明示的普通点标签教学约定：

项目 原关系式 判断
(a) X∈τX\in\tau 成立
(b) {X}∈τ\{X\}\in\tau 不成立
(c) {⌀}∈τ\{\varnothing\}\in\tau 不成立
(d) ⌀∈τ\varnothing\in\tau 成立
(e) ⌀∈X\varnothing\in X 不成立
(f) {⌀}∈X\{\varnothing\}\in X 不成立
(g) {a}∈τ\{a\}\in\tau 成立
(h) a∈τa\in\tau 不成立
(i) ⌀⊂X\varnothing\subset X 成立，且是真包含
(j) {a}∈X\{a\}\in X 不成立
(k) {⌀}⊂τ\{\varnothing\}\subset\tau 成立，且是真包含
(l) a∈Xa\in X 成立
(m) X⊂τX\subset\tau 不成立
(n) {a}⊂τ\{a\}\subset\tau 不成立
(o) {X}⊂τ\{X\}\subset\tau 成立，且是真包含
(p) a⊂τa\subset\tau 按约定类型不合

所以在这个明确约定下，成立的是 (a)、(d)、(g)、(i)、(k)、(l)、(o)，共七项。原页“有且只有6个上述关系式正确”的提示与这些结果不符；我们保留原式和提示，不猜测作者原本想改哪一项。

这七项的成立本身都直接由题设保证，并不依赖“普通点不当作集合”的额外约定。因此，即使不采用该约定，“至少七项成立”仍足以否定原提示的计数。

可选原文说明：为什么完整判断要写明教学约定

原题没有说明这些点自身是否可能是集合。若允许某个点本身就是空集或某个单点集，那么部分成员关系会改变；例如当空集本身是底集中的一个点时，(e) 的 ⌀∈X\varnothing\in X 就成立。

因此，不能把本课约定下的“恰好七项”说成原题在所有可能的点解释下都唯一确定的完整答案。本课明确采用前面棋子式的普通点语境来练习层级区别；原文未限定点的内部结构这一点继续保留，不在这里另开集合论课程。

无论怎样解释点的内部结构，已经确认的七项必真，所以原提示“恰好六项”的问题不受这层语义差异影响。

简短回顾与本段结论

习题 1.1 第 3 题的十六项已按原顺序逐项说明，并保留提示计数及点的解释范围两项原文问题。判断关系式时，先看对象类型，再区分“一个完整对象是否属于右边”与“左边每个元素是否都属于右边”。
