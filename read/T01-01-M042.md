## 方法：用类别保证完整，不能只对上总数

沿用 M041 的两条并交约束。恰好收下一个单点集时，有三个选择，**每个指定选择有五种**拓扑；恰好收下两个单点集时，也有三个选择，**每个指定选择有三种**拓扑。这里改变指定点，仍须保留不同标签的结果。

另两端也要查：没有单点集时，不能同时收下两个不同二点集；三个单点集都有时，三个二点集全被并条件强制收下。下面把这四类一起整理。

## 例题 A

在 $Z=\{u,v,w\}$ 上，一份清单按如下规则声称列完了拓扑：

| 单点集数量 | 清单的规则 |
|---|---|
| 0 | 二点集不选，或只选任意一个：共4个簇 |
| 1 | 指定唯一单点集后，只考虑含这个点的两个二点集，各自可选：共 $3\times4=12$ 个簇 |
| 2 | 指定两个单点集后，收下它们的并；剩下两个二点集各自可选：共 $3\times4=12$ 个簇 |
| 3 | 收下所有子集：共1个簇 |

这份清单总数为29，但是否全部正确且没有遗漏？请修正分类，给出每类的全部选择规则及依据。

## A 解答

<details>
<summary>展开 A 的修补与完整分类</summary>

**总数恰好29不能保证清单正确。**一类遗漏、另一类多列，数目可能正好抵消。

没有单点集时，任意两个不同二点集的交都是单点集，故至多选一个二点集。选零个或三种单选，确有4个；这些选择满足两条并交约束。

恰有一个单点集 $\{p\}$ 时，令 $q,r$ 为其余两点。两个含 $p$ 的二点集 $\{p,q\}$、$\{p,r\}$ 可以各自选，共4种；**还可只选 $\{q,r\}$**。后者不能与前两个同选，因为交会强制出现 $\{q\}$ 或 $\{r\}$。所以每个指定 $p$ 有5种，一共 $3\times5=15$ 个。原清单漏掉3个。

恰有两个单点集 $\{p\},\{q\}$ 时，必须收下 $\{p,q\}$。其余二点集 $\{p,r\}$、$\{q,r\}$ 至多选一个，否则交得不允许的 $\{r\}$。每个指定单点集对只有3种，一共 $3\times3=9$ 个。原清单多列3个不成立的簇。

三个单点集全有时，两两并强制所有二点集；因此只能是离散拓扑，共1个。

修正后的分类为 $4+15+9+1=29$。每一种允许选择都满足 M041 的两条约束，从而满足全部拓扑条件。任何候选必属于四类之一，每类又已穷尽二点集取舍；不同单点集选择或不同二点集选择给出不同成员表。这既说明成立，也说明无遗漏、无重复。

</details>

## 练习 B：教材习题 1.1 第 7(b) 题

**教材原题。**列出集合 $Y=\{a,b,c\}$ 上的所有可能的拓扑。

请保留点标签，写出完整成员表，并说明为什么没有遗漏。只写“共29个”或若干例子不够。

## B 解答

<details>
<summary>尝试原题 7(b) 后展开29个拓扑及完整性证明</summary>

为使成员表易读，统一令

$$\tau=\{\varnothing,Y\}\cup\mathcal F.$$

下表每一行的 $\mathcal F$ 都对应一个拓扑；它列出除空集、底集外的**全部成员**。例如第2行表示 $\{\varnothing,Y,\{a,b\}\}$，不是把 $\{a,b\}$ 中的两个点直接作为拓扑成员。

| 序号 | $\mathcal F$ |
|---|---|
| 1 | $\varnothing$ |
| 2 | $\{\{a,b\}\}$ |
| 3 | $\{\{a,c\}\}$ |
| 4 | $\{\{b,c\}\}$ |
| 5 | $\{\{a\}\}$ |
| 6 | $\{\{a\},\{a,b\}\}$ |
| 7 | $\{\{a\},\{a,c\}\}$ |
| 8 | $\{\{a\},\{a,b\},\{a,c\}\}$ |
| 9 | $\{\{a\},\{b,c\}\}$ |
| 10 | $\{\{b\}\}$ |
| 11 | $\{\{b\},\{a,b\}\}$ |
| 12 | $\{\{b\},\{b,c\}\}$ |
| 13 | $\{\{b\},\{a,b\},\{b,c\}\}$ |
| 14 | $\{\{b\},\{a,c\}\}$ |
| 15 | $\{\{c\}\}$ |
| 16 | $\{\{c\},\{a,c\}\}$ |
| 17 | $\{\{c\},\{b,c\}\}$ |
| 18 | $\{\{c\},\{a,c\},\{b,c\}\}$ |
| 19 | $\{\{c\},\{a,b\}\}$ |
| 20 | $\{\{a\},\{b\},\{a,b\}\}$ |
| 21 | $\{\{a\},\{b\},\{a,b\},\{a,c\}\}$ |
| 22 | $\{\{a\},\{b\},\{a,b\},\{b,c\}\}$ |
| 23 | $\{\{a\},\{c\},\{a,c\}\}$ |
| 24 | $\{\{a\},\{c\},\{a,c\},\{a,b\}\}$ |
| 25 | $\{\{a\},\{c\},\{a,c\},\{b,c\}\}$ |
| 26 | $\{\{b\},\{c\},\{b,c\}\}$ |
| 27 | $\{\{b\},\{c\},\{b,c\},\{a,b\}\}$ |
| 28 | $\{\{b\},\{c\},\{b,c\},\{a,c\}\}$ |
| 29 | $\{\{a\},\{b\},\{c\},\{a,b\},\{a,c\},\{b,c\}\}$ |

**成立与完整性的证明。**

第1—4行没有单点集，二点集至多一个，因此不会产生缺失的单点交，也没有两个单点的并要补。第5—19行分别只含 $\{a\}$、$\{b\}$ 或 $\{c\}$：含该点的两个二点集可以选任意组合；不含该点的二点集只能独选。这正是每个指定单点5种的全部情况。

第20—28行恰含两个单点集。每行收下它们的并，并且对其余两个二点集至多选一个；因此没有交出被排除的第三个单点集。每个指定单点集对有3种。第29行收下全部子集，是离散拓扑。

这些簇都由底集子集组成，且含底集、空集；上述两条关键约束均满足。其余两两运算只有原成员、底集或空集：相同成员不变，两个不同单点交为空，不同二点并为底集，单点与二点或相包含、或不交。因此两两并交闭合。每个子族至多含八个不同成员，可逐次求并；空子族的并为空集。这就给出任意并条件，所有29个簇确实为拓扑。

任何拓扑恰有0、1、2或3个单点集，这四类互不重叠；每类的二点集选择已经穷尽。表中不同行的单点集或二点集至少有一项不同，所以既不遗漏也不重复。

</details>
