关系式的层次 3(e)—(h)

固定编号：T01-01-M028
内容版本：0.1
教材出处：《没有眼泪的拓扑》，书内第 17 页 / PDF 第 17 页，习题 1.1 第 3(e)—(h) 题。
学习目标：根据属于号右边是底集还是集合簇，检查相应层次的成员。

本段主线：完成习题 1.1 第 3 题，分清点、底集和拓扑之间的关系。
当前环节：刚比较了完整对象，现在特别检查属于号右边的对象。
这一步只做：区分“是底集中的点”和“是拓扑中的子集”。

来源说明：B 保留原题第 3(e)—(h) 项；讲解和 A 为新增。沿用 M027 明示的普通点标签教学约定，不把它当作原文附带条件。

方法：先确定正在查看哪份成员表

例如，Y={p,q}Y=\{p,q\} 与 𝒞={⌀,Y,{p}}\mathcal C=\{\varnothing,Y,\{p\}\} 是两份不同的成员表。p∈Yp\in Y 成立，因为 pp 是底集中的点；{p}∈𝒞\{p\}\in\mathcal C 成立，因为这个单点集被收在簇中。

但 {p}∈Y\{p\}\in Y 不成立：YY 列的是点 p,qp,q。同样，p∈𝒞p\in\mathcal C 不成立：𝒞\mathcal C 列的是三个集合，没有直接列入点 pp。

遇到属于关系时，先读右边的成员范围，再把左边完整对象放进去检查；不要因某个点出现在簇的某个成员内部，就说这个点直接属于簇。

例题 A

新增题 A。令 Y={p,q,r}Y=\{p,q,r\}，三个点互不相同，给出

𝒜={⌀,{p,q},Y}. \mathcal A=\{\varnothing,\{p,q\},Y\}.

判断下列关系式并说明依据：

  1. ⌀∈Y\varnothing\in Y；
  2. {p}∈𝒜\{p\}\in\mathcal A；
  3. {p,q}∈𝒜\{p,q\}\in\mathcal A；
  4. p∈Yp\in Y。

A 解答

展开 A 的逐步解答
  1. 不成立。右边是底集 YY，其成员是三个普通点，没有空集。
  2. 不成立。右边是 𝒜\mathcal A，其成员只有 ⌀\varnothing、{p,q}\{p,q\}、YY。单点集 {p}\{p\} 不等于其中任何一个。
  3. 成立。{p,q}\{p,q\} 作为一个完整集合，正是 𝒜\mathcal A 列出的成员。
  4. 成立。右边是底集，点 pp 已被直接列在 YY 中。

虽然 pp 出现在 {p,q}\{p,q\} 里面，这个事实本身并不能推出 {p}∈𝒜\{p\}\in\mathcal A；第二项仍须查成员表。

练习 B：习题 1.1 第 3(e)—(h) 题

仍令 X={a,b,c,d,e,f}X=\{a,b,c,d,e,f\}，τ\tau 为 XX 上的离散拓扑。按本组的普通点标签约定，判断原式并说明理由：

(e) ⌀∈X;(f) {⌀}∈X;(g) {a}∈τ;(h) a∈τ. \text{(e) }\varnothing\in X;\qquad \text{(f) }\{\varnothing\}\in X;\qquad \text{(g) }\{a\}\in\tau;\qquad \text{(h) }a\in\tau.

B 解答

做过 B 后，展开四项解答
  • (e) 不成立。XX 的成员是六个普通点，空集不是其中之一。“空集是 XX 的子集”不能改成“空集是 XX 的元素”。
  • (f) 不成立。{⌀}\{\varnothing\} 是以空集为唯一元素的集合，也不是六个普通点之一；它没有被列为 XX 的成员。
  • (g) 成立。因为 a∈Xa\in X，单点集 {a}\{a\} 是 XX 的子集。τ\tau 是离散拓扑，收下全部这样的子集，所以 {a}∈τ\{a\}\in\tau。
  • (h) 不成立。这里左边是点 aa 本身。按普通点标签约定，它不是由 XX 的点组成的一个集合，因此不是拓扑 τ\tau 的成员。不能把已经成立的 {a}∈τ\{a\}\in\tau 去掉花括号。

前两项检查底集里的点，后两项检查拓扑收下的集合；右边对象的层次不同。

简短回顾

属于底集与属于拓扑是在查两份不同的成员表。原题前八项现已完成；下一步遇到包含号时，要展开左边集合的元素来检查。
