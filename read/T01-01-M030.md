## 方法：先查对象类型，再查元素

例如，对两点集 $Y=\{p,q\}$ 和 $\mathcal C=\{\varnothing,Y,\{p\}\}$，要检查 $Y\subseteq\mathcal C$，就得分别检查点 $p,q$ 是否属于 $\mathcal C$。它们都没有直接列在 $\mathcal C$ 中，因此包含关系不成立。

但 $\{Y\}\subseteq\mathcal C$ 要检查的唯一元素是整个 $Y$，而 $Y$ 确实属于 $\mathcal C$，所以这一个包含关系成立。不能只因为两式都有字母 $Y$ 就作同一判断。

还要先留意左边是不是作为集合给出的对象。按本组的普通点约定，$p$ 只是点标签，未作为有一份元素表的集合来讨论；$p\subset\mathcal C$ 在这个语境下类型不合。不能仅因为写下了包含号，就自动把一个点改成集合 $\{p\}$。

## 例题 A

**新增题 A。**令 $Y=\{p,q\}$ 为两点集，$\mathcal A=\{\varnothing,Y,\{p\}\}$。判断下面的写法；若类型不合，指出问题。成立的包含式还需说明两边不相等。

1. $Y\subset\mathcal A$；
2. $\{\varnothing,Y\}\subset\mathcal A$；
3. $\bigl\{\{q\}\bigr\}\subset\mathcal A$；
4. $p\subset\mathcal A$。

## A 解答

<details>
<summary>展开 A 的逐步解答</summary>

1. **不成立。**$Y$ 的元素是点 $p,q$；例如 $p\notin\mathcal A$，所以不能说 $Y$ 的每个元素都在 $\mathcal A$ 中。
2. **成立，且是真包含。**左边的两个元素 $\varnothing$ 与 $Y$ 都属于 $\mathcal A$；右边另有 $\{p\}$ 这个不同成员，因此两边不相等。
3. **不成立。**左边的唯一元素是单点集 $\{q\}$。它不等于 $\varnothing$、$Y$ 或 $\{p\}$，所以不属于 $\mathcal A$，包含关系失败。
4. **按本组约定类型不合。**$p$ 是一个普通点，没有作为集合给出，不能在这个语境中把它直接放在包含号左边，按集合的元素逐个检查。把它改写成 $\{p\}$ 会得到另一个表达式，不是为原式自动补全记号。

</details>

## 练习 B：习题 1.1 第 3(m)—(p) 题

令 $X=\{a,b,c,d,e,f\}$，$\tau$ 为 $X$ 上的离散拓扑。按本组的普通点标签约定，判断原式并说明理由：

$$
\text{(m) }X\subset\tau;\qquad
\text{(n) }\{a\}\subset\tau;\qquad
\text{(o) }\{X\}\subset\tau;\qquad
\text{(p) }a\subset\tau.
$$

## B 解答

<details>
<summary>做过 B 后，展开四项解答</summary>

- **(m) 不成立。**左边 $X$ 的元素是六个普通点；例如 $a\notin\tau$。$\tau$ 收下的是这些点组成的子集，所以不能把 $X\in\tau$ 换成 $X\subset\tau$。
- **(n) 不成立。**左边只有元素 $a$，因此包含关系要求 $a\in\tau$，而这在普通点标签约定下不成立。已经成立的 $\{a\}\in\tau$ 不能作为它的依据。
- **(o) 成立，且是真包含。**左边的唯一元素是 $X$，拓扑条件 (i) 保证 $X\in\tau$，所以 $\{X\}\subseteq\tau$。又有 $\varnothing\in\tau$ 且 $\varnothing\ne X$，所以两边不相等。
- **(p) 按本组约定类型不合。**$a$ 是普通点标签，未作为集合给出；这里不能使用对子集逐元素检查的写法，也不能擅自把原式的 $a$ 改成 $\{a\}$。

本组唯一成立的包含式 (o) 两边不相等，因此把原文 $\subset$ 理解为真包含或允许相等的包含，均得到相同判断。

</details>

## 习题 1.1 第 3 题：全部关系式核对

<details>
<summary>完成十六项后，展开总核对</summary>

以下完整判断采用本组已明示的普通点标签教学约定：

| 项目 | 原关系式 | 判断 |
|---|---|---|
| (a) | $X\in\tau$ | 成立 |
| (b) | $\{X\}\in\tau$ | 不成立 |
| (c) | $\{\varnothing\}\in\tau$ | 不成立 |
| (d) | $\varnothing\in\tau$ | 成立 |
| (e) | $\varnothing\in X$ | 不成立 |
| (f) | $\{\varnothing\}\in X$ | 不成立 |
| (g) | $\{a\}\in\tau$ | 成立 |
| (h) | $a\in\tau$ | 不成立 |
| (i) | $\varnothing\subset X$ | 成立，且是真包含 |
| (j) | $\{a\}\in X$ | 不成立 |
| (k) | $\{\varnothing\}\subset\tau$ | 成立，且是真包含 |
| (l) | $a\in X$ | 成立 |
| (m) | $X\subset\tau$ | 不成立 |
| (n) | $\{a\}\subset\tau$ | 不成立 |
| (o) | $\{X\}\subset\tau$ | 成立，且是真包含 |
| (p) | $a\subset\tau$ | 按约定类型不合 |

所以在这个明确约定下，成立的是 **(a)、(d)、(g)、(i)、(k)、(l)、(o)，共七项**。原页“有且只有6个上述关系式正确”的提示与这些结果不符；我们保留原式和提示，不猜测作者原本想改哪一项。

这七项的成立本身都直接由题设保证，并不依赖“普通点不当作集合”的额外约定。因此，即使不采用该约定，“至少七项成立”仍足以否定原提示的计数。

</details>

<details>
<summary>可选原文说明：为什么完整判断要写明教学约定</summary>

原题没有说明这些点自身是否可能是集合。若允许某个点本身就是空集或某个单点集，那么部分成员关系会改变；例如当空集本身是底集中的一个点时，(e) 的 $\varnothing\in X$ 就成立。

因此，不能把本课约定下的“恰好七项”说成原题在所有可能的点解释下都唯一确定的完整答案。本课明确采用前面棋子式的普通点语境来练习层级区别；原文未限定点的内部结构这一点继续保留，不在这里另开集合论课程。

无论怎样解释点的内部结构，已经确认的七项必真，所以原提示“恰好六项”的问题不受这层语义差异影响。

</details>
