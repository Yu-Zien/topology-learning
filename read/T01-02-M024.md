# 四点四成员拓扑的枚举框架

固定编号：T01-02-M024

学习目标：区分互补对的交换重复与严格链的方向，建立完整枚举方法。

> **本段主线：**列全原题6(ii)的四成员拓扑。  
> **当前环节：**已有一般分类，先明确怎样避免重复计数。  
> **这一步只做：**给每一类选定唯一的写法。

来源说明：分类依据来自已证原题6(i)，A/B与排列规则新增；本模块不记为完成6(ii)。

## 方法：互补对不分先后，严格链固定小者在前

拓扑 $\{\varnothing,X,A,B\}$ 交换 $A,B$ 后还是同一个成员表。互补时，可固定含指定点的那块写作 $A$，这样每一对只出现一次。

严格链则写成 $A\subsetneq B$，固定小者在前。两个不同的严格链不会因为交换顺序成为新的同一写法。M023已证明互补类与严格链类不会重叠。

## 例题 A

在 $Y=\{p,q,r\}$ 上列全四成员拓扑。每行只写两个额外成员 $A,B$，统一添上 $\varnothing,Y$；说明分类完整。

## A 解答

<details>
<summary>展开 A 的9种情况</summary>

互补类有3对：

| $A$ | $B$ |
|---|---|
| $\{p\}$ | $\{q,r\}$ |
| $\{p,q\}$ | $\{r\}$ |
| $\{p,r\}$ | $\{q\}$ |

严格链只能是单点包含于二点集，共6条：

| $A$ | $B$ |
|---|---|
| $\{p\}$ | $\{p,q\}$ |
| $\{p\}$ | $\{p,r\}$ |
| $\{q\}$ | $\{p,q\}$ |
| $\{q\}$ | $\{q,r\}$ |
| $\{r\}$ | $\{p,r\}$ |
| $\{r\}$ | $\{q,r\}$ |

任何四成员拓扑都在这两类中；互补对只写含p的块在前，严格链只写小者在前。每行不同且两类互斥，所以恰有9个。每行都是拓扑，由M023的可行性核验保证。

</details>

## 练习 B

在 $X=\{1,2,3,4\}$ 上，只列出四成员拓扑中的**互补类**。固定 $1\in A$ 来避免交换重复，说明为何没有漏掉这一类中的任何拓扑。此处不要求列严格链类。

## B 解答

<details>
<summary>尝试 B 后展开7个互补对</summary>

每个互补对恰好有一块含1，所以可以且只能选那块作 $A$。$A$ 是包含1的非空真子集，对2、3、4各自决定是否加入，排除全部加入而使 $A=X$ 的情形，得到

| $A$ | $B=X\setminus A$ |
|---|---|
| $\{1\}$ | $\{2,3,4\}$ |
| $\{1,2\}$ | $\{3,4\}$ |
| $\{1,3\}$ | $\{2,4\}$ |
| $\{1,4\}$ | $\{2,3\}$ |
| $\{1,2,3\}$ | $\{4\}$ |
| $\{1,2,4\}$ | $\{3\}$ |
| $\{1,3,4\}$ | $\{2\}$ |

共有 $2^3-1=7$ 对。每对恰写一次，添上底集、空集便是这一类的全部拓扑。原题6(ii)还需要下一模块的严格链类。

</details>

## 简短回顾

互补类固定指定点所在块，严格链固定包含方向。这两个唯一写法让最终列表可以检验重复与遗漏。
