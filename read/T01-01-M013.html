任意底集上的离散拓扑

固定编号：T01-01-M013
内容版本：0.1
教材出处：《没有眼泪的拓扑》，书内第 14 页 / PDF 第 14 页，例 1.1.6 后关于三条件的说明。
学习目标：用“并、交的结果仍是底集的子集”核验全部子集组成的簇满足拓扑三条件。

本段主线：认识可放在任意非空底集上的两种拓扑。
当前环节：已经知道离散构造收下什么，现在完成例 1.1.6 的核验。
这一步只做：说明这个构造在有限或无限底集上都满足定义 1.1.1。

来源说明：教材在例 1.1.6 后指出这个簇满足拓扑三条件；下面的短例、完整论证与 B 为新增展开。原页此处回指“定义 1.1.6”，但前文实际标题是“例 1.1.6”，本课按实际标题标注出处。

证明中的一步：只需确认运算结果仍是底集的子集

例如，在 X={a,b,c}X=\{a,b,c\} 中，取两个子集 {a,b}\{a,b\} 和 {b,c}\{b,c\}。它们的并为 XX，交为 {b}\{b\}，两种结果仍是 XX 的子集。由于离散构造收下全部子集，结果也就属于这个簇。

这是具体例子，还没有覆盖所有底集和所有选择。一般核验用同一个理由：

  • 并不会从底集外带来新元素。一个元素能进入并集，必须来自某个参与集合；参与集合全是底集的子集，所以这个元素仍在底集中。
  • 交只保留共同元素。一个元素能进入两个集合的交，就已经在这两个集合中，因此也在底集中。

写证明时，“任意选取一批成员”表示不额外限定选哪些，也不限定只选有限多个。“取这个并中的任一元素”则表示下面的理由要对其中每个元素成立，而不只检查某个指定的点。这样得到的是“整个并是底集的子集”，而不是一次抽查。

例题 A：例 1.1.6 的完整核验

教材结论的新增展开题 A。设 XX 为任意非空集合，τ\tau 由 XX 的全部子集组成。按定义 1.1.1 证明 τ\tau 是 XX 上的拓扑；不假设 XX 有限。

A 解答

展开 A 的完整证明

按构造，τ\tau 的每个成员都是 XX 的子集，首先满足“XX 的子集簇”这一要求。

条件 (i)：底集与空集。XX 和 ⌀\varnothing 都是 XX 的子集，因而都属于 τ\tau。

条件 (ii)：任意并。从 τ\tau 中任意选取有限或无限多个成员，将它们的并记为 UU。

对 UU 中任一元素 uu，按并集定义，uu 至少属于一个被选的集合。那个集合是 XX 的子集，所以 u∈Xu\in X。这对 UU 中每个元素都成立，故 U⊆XU\subseteq X。而 τ\tau 收下 XX 的全部子集，因此 U∈τU\in\tau。

如果所选集合全都不贡献元素，结果就是空集，也已经在 τ\tau 中；没有选任何成员时同样得到空集。这里并不要求 UU 有限。

条件 (iii)：两两交。任取 A,B∈τA,B\in\tau。它们都是 XX 的子集。对 A∩BA\cap B 中任一元素 uu，有 u∈Au\in A 且 u∈Bu\in B，于是 u∈Xu\in X。因此 A∩B⊆XA\cap B\subseteq X，从而 A∩B∈τA\cap B\in\tau。交集为空时也包含在这个结论里。

三条件均成立，故 τ\tau 是 XX 上的拓扑。论证没有用到底集或所选子族的有限性，所以覆盖任意非空底集。

练习 B

新增题 B。令 ℕ={1,2,3,…}\mathbb N=\{1,2,3,\ldots\}，σ\sigma 由 ℕ\mathbb N 的全部子集组成。按与 A 相同的方法，证明 σ\sigma 是 ℕ\mathbb N 上的拓扑。

请在证明中解释：为什么 M011 中的无限并 {2}∪{3}∪⋯\{2\}\cup\{3\}\cup\cdots 在这里不再造成失败。不要只检查这一个并就结束任意并的核验。

B 解答

做过 B 后，展开完整证明

σ\sigma 按构造是 ℕ\mathbb N 的子集簇。

条件 (i)。ℕ\mathbb N 和 ⌀\varnothing 都是 ℕ\mathbb N 的子集，所以属于 σ\sigma。

条件 (ii)。从 σ\sigma 中任意选取一批成员，允许有无限多个，记它们的并为 VV。若 u∈Vu\in V，则 uu 来自某个参与集合；那个集合的所有元素都是正整数，所以 u∈ℕu\in\mathbb N。因此 V⊆ℕV\subseteq\mathbb N，而 σ\sigma 收下全部这样的子集，故 V∈σV\in\sigma。并为空集以及没有选任何成员的情形也成立。

特别地，{2}∪{3}∪⋯={2,3,4,…}\{2\}\cup\{3\}\cup\cdots=\{2,3,4,\ldots\} 虽然无限，却仍是 ℕ\mathbb N 的子集，所以属于 σ\sigma。M011 的簇只收有限子集、空集与整个 ℕ\mathbb N；这里收下全部子集，成员范围已经不同。前一段的一般理由覆盖所有选择，这个具体并只是其中一次应用。

条件 (iii)。任取 C,D∈σC,D\in\sigma。交集 C∩DC\cap D 中的每个元素都在 CC 中，因而是正整数。所以 C∩D⊆ℕC\cap D\subseteq\mathbb N，从而 C∩D∈σC\cap D\in\sigma。若没有共同元素，交集为空集，也已被收下。

三条件都满足，故 σ\sigma 是 ℕ\mathbb N 上的拓扑。

T01-01-R006

问题：在全部子集组成的簇中，为什么允许无限多个成员求并也不会使结果跑到簇外？

回忆后查看答案

并中的每个元素都来自某个参与集合，因而仍属于底集。无论参与集合有多少个，结果都还是底集的子集；这个簇收下全部子集，所以也收下这个并。

简短回顾与本段结论

例 1.1.6 的核验已经完成：任意非空底集的全部子集组成的簇都是拓扑。关键不是子集能否列完，而是并、交的结果仍是底集的子集。
