## 方法：某一单点闭不足以满足全称条件

在末尾段拓扑中，$\{1\}$ 的补集 $F_2=\{2,3,\ldots\}$ 开，所以它闭。但 $\{2\}$ 的补集 $\{1,3,4,\ldots\}$ 不是任何末尾段：它含1却漏2。故空间仍不T1。

## 例题 A

逐项验证上面的两个单点，并说明哪一个决定T1结论。

## A 解答

<details>
<summary>展开 A 的全称判断</summary>

$\mathbb N\setminus\{1\}=F_2$ 开，所以 $\{1\}$ 闭。$\mathbb N\setminus\{2\}$ 非空、非底集；若等于F_n，含1迫使n=1，从而也应含2，矛盾。所以它不开，$\{2\}$ 不闭。

T1要求每个单点闭，失败的 $\{2\}$ 决定空间不T1。

</details>

## 练习 B：教材习题1.3第3(ix)题及整题汇总

## B 解答

<details>
<summary>尝试第3(ix)题后展开解答与汇总</summary>

末尾段拓扑不T1，因为 $\{2\}$ 的补集 $\{1,3,4,\ldots\}$ 不是空集、底集或任何末尾段。

九项汇总：

| 小问 | T1? | 依据 |
|---|---|---|
| (i)离散空间 | 是 | 所有单点补集开 |
| (ii)至少两点平庸空间 | 否 | 单点补集为非空真子集 |
| (iii)无限有限闭空间 | 是 | 所有单点有限，因而闭 |
| (iv)例1.1.2 | 否 | $\{b\}$ 不闭 |
| (v)整数圆括号实区间簇 | 否 | $\mathbb R\setminus\{0\}$ 不是有界区间 |
| (vi)整数方括号实区间簇 | 否 | 同一补集不是有界方括号区间 |
| (vii)整数起点实射线簇 | 否 | 同一补集向左无界 |
| (viii)正整数初始段 | 否 | $\mathbb N\setminus\{1\}$ 不是初始段 |
| (ix)正整数末尾段 | 否 | $\mathbb N\setminus\{2\}$ 不是末尾段 |

恰有(i)(iii)两个T1空间，与教材提示一致；一致的数量只是逐项核验后的复核。

</details>
