拓扑的基：用一族集合生成全部开集

固定编号：T02-02-M003
内容版本：0.1
教材出处：《没有眼泪的拓扑》，书内第 34 页 / PDF 第 34 页，定义2.2.2。
学习目标：根据“每个开集都是基元素的并”判断一个开集族是否为给定拓扑的基。

本段主线：把“开区间生成全部实数开集”抽象成任意拓扑的基。
当前环节：正式定义基，并分清基元素与由它们生成的全部开集。
这一步只做：检查候选族中的成员都开，以及每个开集都能由它们并成。

来源说明：定义2.2.2及“基生成拓扑”的解释来自教材；有限例A/B为新增讲练。

定义2.2.2：完整陈述

设 (X,τ)(X,\tau) 为拓扑空间。由X中开集组成的集合簇 ℬ\mathcal B 称为拓扑 τ\tau 的一个 基，如果每个开集都是 ℬ\mathcal B 中成员的并。

因此要验证 ℬ\mathcal B 是给定拓扑的基，需要两点：

  1. ℬ⊆τ\mathcal B\subseteq\tau，即每个基元素本身开；
  2. 每个 U∈τU\in\tau 都能写成某些 B∈ℬB\in\mathcal B 的并。

空集可由空族基元素的并得到。基通常比整个拓扑小，但定义不要求一定更小，也不要求表示唯一。

例题 A

令 X={p,q}X=\{p,q\}，

τ={⌀,{p},X},ℬ={{p},X}. \tau=\{\varnothing,\{p\},X\},\qquad \mathcal B=\{\{p\},X\}.

证明 ℬ\mathcal B 是 τ\tau 的一个基。

A 解答

展开 A 的两项检查

{p}\{p\} 与X都属于τ，所以 ℬ⊆τ\mathcal B\subseteq\tau。

再列出τ的全部开集：⌀\varnothing 是空族基元素的并；{p}\{p\} 是单个基元素 {p}\{p\} 的并；X是单个基元素X的并。因此每个τ中成员都由基元素并成，ℬ\mathcal B 是τ的基。

练习 B

仍用上述X与τ，令 𝒞={{p}}\mathcal C=\{\{p\}\}。判断 𝒞\mathcal C 是否为τ的基，并指出哪一个开集无法生成。

B 解答

尝试 B 后展开判断

𝒞\mathcal C 的唯一成员 {p}\{p\} 确实开，但由它能得到的并只有 ⌀\varnothing 与 {p}\{p\}。开集X无法写成 𝒞\mathcal C 中成员的并，所以 𝒞\mathcal C 不是τ的基。

候选成员都开只是必要条件，还必须生成每个开集。

简短回顾

基是一族开集；把任意子族并起来应能得到拓扑中的每个开集，不能只检查基元素本身开。
