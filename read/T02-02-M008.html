会生成一个集合簇不等于生成拓扑

固定编号：T02-02-M008
内容版本：0.1
教材出处：《没有眼泪的拓扑》，书内第 35 页 / PDF 第 35 页，例2.2.7。
学习目标：列出候选族的全部并后，继续检查所得集合簇的交条件，避免把任意子集族误称为某拓扑的基。

本段主线：找出一个子集族能够成为某个拓扑的基所需的内在条件。
当前环节：前面从已知拓扑检查基；现在只有候选族，先看它生成的集合簇是否真是拓扑。
这一步只做：用一次两两交失败否定生成结果。

来源说明：三点底集、候选族、全部并集簇及交失败见证来自例2.2.7；A/B为新增讲练。

例2.2.7：缺少交所需的局部积木

令

X={a,b,c},ℬ={{a},{c},{a,b},{b,c}}. X=\{a,b,c\},\qquad \mathcal B=\{\{a\},\{c\},\{a,b\},\{b,c\}\}.

若它是某个拓扑的基，那个拓扑必须由全部基元素并组成，即

τ={X,⌀,{a},{c},{a,c},{a,b},{b,c}}. \tau=\{X,\varnothing,\{a\},\{c\},\{a,c\},\{a,b\},\{b,c\}\}.

但是

{a,b}∩{b,c}={b}∉τ. \{a,b\}\cap\{b,c\}=\{b\}\notin\tau.

所以τ不是拓扑，ℬ\mathcal B 不能成为X上任何拓扑的基。

例题 A

验证上述τ确实是 ℬ\mathcal B 的全部不同子族并，并说明为什么缺少 {b}\{b\} 会破坏拓扑条件。

A 解答

展开 A 的并集清单与交见证

空族并为 ⌀\varnothing。单个基元素给 {a}\{a\}、{c}\{c\}、{a,b}\{a,b\}、{b,c}\{b,c\}；{a}∪{c}={a,c}\{a\}\cup\{c\}=\{a,c\}；任何把左右两侧连起来的并都会得到X。没有子族并能只留下b，所以全部不同结果正是所列七个集合。

拓扑必须对两两交封闭。两个已经在τ中的集合 {a,b}\{a,b\} 与 {b,c}\{b,c\} 的交是 {b}\{b\}，却不在τ中。因此τ不是拓扑，候选族也不可能是某拓扑的基。

练习 B

令 Y={p,q,r}Y=\{p,q,r\}，

𝒞={{p,q},{q,r}}. \mathcal C=\{\{p,q\},\{q,r\}\}.

列出所有 𝒞\mathcal C 成员的并所得到的集合簇，并判断 𝒞\mathcal C 能否成为Y上某个拓扑的基。

B 解答

尝试 B 后展开判断

所有不同子族并为

⌀,{p,q},{q,r},Y. \varnothing,\quad\{p,q\},\quad\{q,r\},\quad Y.

若 𝒞\mathcal C 是某拓扑的基，该拓扑只能是这四个集合组成的簇。但

{p,q}∩{q,r}={q} \{p,q\}\cap\{q,r\}=\{q\}

不在该簇中，所以两两交条件失败。故 𝒞\mathcal C 不是Y上任何拓扑的基。

T02-02-R003

问题：为什么“把候选族的所有并收集起来”还不足以保证候选族是某个拓扑的基？

回忆后查看答案

这样得到的集合簇自动对任意并封闭，却仍可能不对两两交封闭。例2.2.7中 {a,b}\{a,b\} 与 {b,c}\{b,c\} 都能生成，但交 {b}\{b\} 无法由基元素并成，所以生成簇不是拓扑。

简短回顾

候选族的全部并一定形成“可生成的集合”，但还必须通过拓扑的交条件；失败的交会暴露缺少的基元素。
