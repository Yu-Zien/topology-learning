初始段拓扑 6(i)

固定编号：T01-01-M038
内容版本：0.1
教材出处：《没有眼泪的拓扑》，书内第 17 页 / PDF 第 17 页，习题 1.1 第 6(i) 题。
学习目标：按所选长度指标分类，证明正整数初始段组成的候选簇满足拓扑三条件。

本段主线：完成习题 6 中正整数集上的两种拓扑。
当前环节：先处理从 11 开始、长度变化的初始段。
这一步只做：把指标的最大值或无界性转成并集的准确结果。

来源说明：B 保留教材原题及 initial segment 名称；中文“初始段”、方法说明、A 和参考解为新增讲练。这里 ℕ={1,2,3,…}\mathbb N=\{1,2,3,\ldots\}，不含 00。

方法：长度越大，初始段越大

记 In={1,2,…,n}I_n=\{1,2,\ldots,n\}。例如 I2⊆I5I_2\subseteq I_5，所以 I2∪I5=I5I_2\cup I_5=I_5、I2∩I5=I2I_2\cap I_5=I_2。

任意选一批 InI_n 时，沿用 M034 的指标分类：没有选中初始段时并为空；长度有界且非空时，最大的被选长度给出整个并；长度无界时，给定任意正整数 kk，都能选到一个长度至少为 kk 的段，因此并包含每个正整数。每一段有限，并不意味着任意多段的并有限。

例题 A

令 En={1,2,…,2n}E_n=\{1,2,\ldots,2n\}，其中 n∈ℕn\in\mathbb N。证明

𝒞={ℕ,⌀}∪{En:n∈ℕ}\mathcal C=\{\mathbb N,\varnothing\}\cup\{E_n:n\in\mathbb N\}

是 ℕ\mathbb N 上的拓扑。这里只允许偶数长度的普通初始段。

A 解答

展开 A 的三条件证明

每个成员都是 ℕ\mathbb N 的子集，且 ℕ,⌀∈𝒞\mathbb N,\varnothing\in\mathcal C。

任取子族 𝒟⊆𝒞\mathcal D\subseteq\mathcal C。若 ℕ∈𝒟\mathbb N\in\mathcal D，并就是 ℕ\mathbb N。否则空集不影响并，令 J={n∈ℕ:En∈𝒟}J=\{n\in\mathbb N:E_n\in\mathcal D\}。

  • J=⌀J=\varnothing：并为 ⌀\varnothing，包括没有选任何成员的情况。
  • JJ 非空有界：取实际属于 JJ 的最大元素 mm。每个参与的 EnE_n 都包含在 EmE_m 中，且 EmE_m 自身参与，所以并为 EmE_m。
  • JJ 无界：任取 k∈ℕk\in\mathbb N，可以取 n∈Jn\in J 且 n≥kn\ge k，于是 k≤2nk\le2n，故 k∈Enk\in E_n。反向包含成立，因为所有 En⊆ℕE_n\subseteq\mathbb N。因此并为 ℕ\mathbb N。

三种并的结果都属于 𝒞\mathcal C。

两个普通成员的交为 Em∩En=Emin⁡(m,n)E_m\cap E_n=E_{\min(m,n)}，仍是允许的偶数长度段。与底集相交得到原成员，与空集相交得到空集。因此三条件全部满足。

练习 B：教材习题 1.1 第 6(i) 题

教材原题。令 ℕ\mathbb N 为所有正整数组成的集合。τ1\tau_1 由 ℕ\mathbb N、⌀\varnothing 及所有形如 {1,2,…,n}\{1,2,\ldots,n\} 的集合构成，这里 nn 为任意正整数。证明 τ1\tau_1 是 ℕ\mathbb N 上的一个拓扑。此拓扑称为 initial segment 拓扑。

B 解答

尝试原题 6(i) 后展开参考解

令 In={1,2,…,n}I_n=\{1,2,\ldots,n\}。每个 In⊆ℕI_n\subseteq\mathbb N，且 ℕ\mathbb N 和 ⌀\varnothing 已在 τ1\tau_1 中。

任取 𝒟⊆τ1\mathcal D\subseteq\tau_1。若其中含 ℕ\mathbb N，并为 ℕ\mathbb N；否则令 J={n∈ℕ:In∈𝒟}J=\{n\in\mathbb N:I_n\in\mathcal D\}，忽略可能参与的空集。

若 JJ 为空，并为空集。若 JJ 非空有界，M034 保证 m=max⁡Jm=\max J 存在且属于 JJ。每个参与的 InI_n 都包含于 ImI_m，而 ImI_m 也参与，所以并为 Im∈τ1I_m\in\tau_1。

若 JJ 无界，任取 k∈ℕk\in\mathbb N，存在 n∈Jn\in J 满足 n≥kn\ge k，于是 k∈In⊆⋃n∈JInk\in I_n\subseteq\bigcup_{n\in J}I_n。反过来，参与集合均为 ℕ\mathbb N 的子集。因此 ⋃n∈JIn=ℕ∈τ1\bigcup_{n\in J}I_n=\mathbb N\in\tau_1。这覆盖全部允许子族，任意并条件成立。

对任意正整数 m,nm,n，

Im∩In=Imin⁡(m,n)∈τ1.I_m\cap I_n=I_{\min(m,n)}\in\tau_1.

与 ℕ\mathbb N 或 ⌀\varnothing 相交的结果也在 τ1\tau_1 中，故两两交条件成立。于是 τ1\tau_1 是拓扑。

简短回顾

初始段的无界长度能覆盖每个正整数；有界非空的长度取最大值给出并，两个初始段取最小长度给出交。
