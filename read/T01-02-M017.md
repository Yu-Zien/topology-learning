## 方法：可先确定两个短表，再核对每一行

对固定拓扑，开集就是原成员表；闭集是该表各成员的补集。某候选同时在两个表中就是闭开，只在其中一个表中就只有对应性质，两个表都没有则均非。即使利用这个方法减少重复计算，最终仍要列出原题所要求的全部对象。

## 例题 A

令 $Z=\{1,2,3\}$，$\sigma=\{\varnothing,Z,\{1\},\{1,2\}\}$。列出8个子集的完整开闭分类。

## A 解答

<details>
<summary>展开 A 的8项完整表</summary>

闭集表为 $\varnothing,Z,\{2,3\},\{3\}$，由全部开集取补集得到。

| 子集 | 分类 |
|---|---|
| $\varnothing$ | 闭开 |
| $\{1\}$ | 开但不闭 |
| $\{2\}$ | 既不开又不闭 |
| $\{3\}$ | 闭但不开 |
| $\{1,2\}$ | 开但不闭 |
| $\{1,3\}$ | 既不开又不闭 |
| $\{2,3\}$ | 闭但不开 |
| $Z=\{1,2,3\}$ | 闭开 |

每一行只比较自身是否在开集表、是否在闭集表；8个不同子集已列全。

</details>

所引用的完整条件为

$$X=\{a,b,c,d,e,f\},\quad
\tau_1=\{X,\varnothing,\{a\},\{c,d\},\{a,c,d\},\{b,c,d,e,f\}\}.$$
