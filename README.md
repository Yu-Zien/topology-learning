# 拓扑学习 · 私有课件与网站快照

此仓库保持私有，未开通 GitHub Pages，也没有公开网站。

- [课件目录与 Markdown 阅读入口](COURSES.md)
- [课件索引](read/catalog.json)
- `read/*.md`：35份课件的可读原文，保留固定编号、公式写法、题目、参考解和来源说明；本机绝对链接已改为相对链接。
- 根目录 HTML 与 `runtime/`：可运行的静态学习网站产物；GitHub 仓库页面本身不会运行它。
- `read/*.html`：不写入学习记录的静态课件阅读页，需通过本地 HTTP 预览或下载后查看。

## 让聊天窗口读取

聊天窗口必须有访问本私有仓库的授权及相应工具。只粘贴仓库链接不会授予访问权限，也不会自动继承其他聊天窗口或本机的登录。

可以让已授权的窗口先读取 `COURSES.md`，再读取所需的 `read/T01-01-Mxxx.md`。例如：读取 M018b，解释其两个包含方向的证明思路。

仓库不包含教材 PDF、个人学习进度、备份、聊天记录、本机服务日志或内部执行文档。读取课件不会得知本人学到哪里。

## 使用网站与备份

当前仍使用本机网站学习。学习记录继续留在原浏览器和原地址。
未来如果更换网站地址或设备，需要从旧地址导出备份，再在新地址恢复；上传本仓库不产生云同步。
